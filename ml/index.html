1장

머신러닝이란 무엇인가

교재: Goodfellow 1장, 5.1절 · Murphy 1.1–1.3절

정의 · Mitchell (1997), Goodfellow 5.1절에서 인용

컴퓨터 프로그램이 어떤 과제 T에서 성능 척도 P로 잰 성능이 경험 E를 통해 나아진다면, 그 프로그램은 T와 P에 대해 E로부터 학습한다고 말한다.

Murphy(1.1절)는 머신러닝을 데이터에서 패턴을 자동으로 찾아내고, 찾은 패턴으로 미래 데이터를 예측하거나 불확실한 상황에서 결정을 내리는 방법들의 모음이라고 정의합니다. 규칙을 사람이 일일이 적는 대신, 예시를 보여 주고 규칙을 찾게 하는 것입니다.

학습의 세 갈래

  • 지도 학습은 입력 x와 정답 y의 쌍으로 이루어진 학습 데이터에서 x를 y로 보내는 함수를 배웁니다. y가 범주(스팸, 정상 메일)이면 분류, 실수(집값, 기온)이면 회귀라고 합니다.
  • 비지도 학습은 정답 없이 입력만 받아 데이터 안의 구조를 찾습니다. 비슷한 것끼리 묶는 군집화, 데이터를 적은 수의 축으로 요약하는 차원 축소가 대표적입니다. 무엇을 찾을지 미리 정해져 있지 않아 지도 학습보다 문제가 덜 명확합니다.
  • 강화 학습은 가끔 주어지는 보상이나 벌을 보고 어떻게 행동할지 배웁니다. Murphy는 아기가 걷는 법을 배우는 과정을 예로 듭니다.

입력의 각 항목을 특징(feature)이라고 합니다. 사람의 키와 몸무게처럼 숫자 벡터일 수도 있고, 이미지, 문장, 시계열처럼 구조가 있는 대상일 수도 있습니다 (Murphy 1.1.1절).

2장

확률과 베이즈 규칙

교재: Murphy 2.2–2.4절 · Goodfellow 3.5, 3.9, 3.11절

머신러닝은 불확실성을 다룹니다. 데이터에는 잡음이 있고, 같은 입력에도 정답이 하나로 정해지지 않을 때가 많습니다. 그래서 모델의 출력은 흔히 "이 메일이 스팸일 확률 0.93"처럼 확률로 나옵니다.

조건부 확률 p(A | B)는 B가 일어났을 때 A가 일어날 확률입니다. 베이즈 규칙은 원인에서 결과로 가는 확률 p(결과 | 원인)을, 결과에서 원인으로 거슬러 가는 확률 p(원인 | 결과)로 바꿔 줍니다.

p(y | x) = p(x | y) · p(y) / p(x), p(x) = Σy′ p(x | y′) · p(y′)p(y)는 데이터를 보기 전의 믿음인 사전 확률, p(x | y)는 가능도, p(y | x)는 데이터를 본 뒤의 사후 확률입니다 (Murphy 식 2.7).

Murphy(2.2.3.1절)의 예를 봅시다. 40대 여성이 유방암 검사(유방 촬영술)를 받아 양성이 나왔습니다. 검사의 민감도는 80%, 즉 암이 있으면 80% 확률로 양성이 나옵니다. 그렇다면 암일 확률은 80%일까요? 많은 사람이 그렇게 답하지만 틀렸습니다. 이 연령대에서 암이 있을 사전 확률은 0.4%로 매우 낮고, 암이 없어도 10%는 양성이 나옵니다. 베이즈 규칙으로 계산하면 실제 확률은 약 3%입니다. 사전 확률을 무시하는 이 실수를 기저율 오류라고 합니다.

정규분포

연속값을 다룰 때 가장 많이 쓰는 분포는 정규(가우스) 분포 N(x; μ, σ²)입니다. 평균 μ를 중심으로 종 모양이고, 표준편차 σ가 퍼짐을 정합니다. 3장의 선형회귀는 "정답 = 직선 + 정규분포 잡음"이라는 가정으로 볼 수 있습니다 (Goodfellow 3.9.3, 5.5.1절).

3장

선형회귀와 최소제곱

교재: Goodfellow 5.1.4절, 4.5절 · Murphy 1.4.5절, 7.1–7.3절

선형회귀는 입력 x에서 실수 y를 예측하는 가장 단순한 모델입니다. 입력이 하나라면 예측은 직선 ŷ = wx + b이고, 기울기 w와 절편 b가 모델의 매개변수입니다. 학습이란 데이터를 가장 잘 설명하는 w와 b를 찾는 일입니다.

"가장 잘"을 재는 기준이 비용 함수입니다. 선형회귀는 보통 평균제곱오차(MSE)를 씁니다. 예측과 정답의 차이(잔차)를 제곱해 평균한 값입니다. 제곱을 하므로 크게 틀린 점일수록 벌점이 훨씬 커집니다.

MSE(w, b) = (1/m) Σi (wxi + b − yi)², 최적해: w = (XᵀX)⁻¹Xᵀym은 학습 예의 수입니다. 기울기가 0이 되는 조건을 풀면 정규 방정식이 나옵니다 (Goodfellow 식 5.12, Murphy 7.3.1절). X는 각 행이 [xi, 1]인 행렬입니다.

4장

경사하강법

교재: Goodfellow 4.3절, 5.9절 · Murphy 8.3.2절, 8.5.2절

선형회귀는 정규 방정식으로 한 번에 풀리지만, 대부분의 모델은 그런 공식이 없습니다. 그래서 비용을 조금씩 줄여 가는 반복 방법을 씁니다. 기울기(gradient) ∇f는 함수가 가장 가파르게 오르는 방향을 가리킵니다. 그 반대 방향으로 조금 움직이면 비용이 줄어듭니다. 이것이 경사하강법입니다.

x′ = x − ε ∇x f(x)ε는 한 번에 움직이는 크기인 학습률입니다 (Goodfellow 식 4.5). 학습률은 사람이 미리 정하는 값이라 하이퍼파라미터라고 부릅니다.

학습률이 너무 작으면 수렴이 느리고, 너무 크면 골짜기를 건너뛰어 오히려 비용이 커질 수 있습니다 (Goodfellow 4.3.1절). 비용 곡면이 한 방향으로만 길쭉하면, 곧 헤세 행렬의 조건수가 크면 경사하강법은 골짜기 벽 사이를 지그재그로 오가며 느려집니다.

데이터가 많으면 기울기를 매번 전체 데이터로 계산하기 어렵습니다. 확률적 경사하강법(SGD)은 데이터에서 무작위로 뽑은 작은 묶음(미니배치)으로 기울기를 추정합니다. 경로가 흔들리지만 한 걸음이 훨씬 싸서, 딥러닝 학습의 기본 방법이 되었습니다 (Goodfellow 5.9절).

5장

과적합과 일반화

교재: Goodfellow 5.2–5.4절 · Murphy 1.4.7–1.4.8절, 6.4.4절, 7.5절

머신러닝의 목표는 학습 데이터를 외우는 것이 아니라, 처음 보는 데이터에서도 잘 맞히는 것입니다. 이 능력을 일반화라고 합니다. 학습 데이터에서의 오차를 학습 오차, 새 데이터에서의 기대 오차를 일반화 오차(테스트 오차)라고 합니다.

모델이 표현할 수 있는 함수의 다양성을 용량(capacity)이라고 합니다. 용량이 너무 작으면 학습 데이터조차 설명하지 못하는 과소적합이 생기고, 너무 크면 학습 데이터의 잡음까지 외워 새 데이터에서 틀리는 과적합이 생깁니다. Goodfellow 그림 5.2는 이차 함수에서 만든 데이터에 1차, 2차, 9차 다항식을 맞춘 예입니다. 1차는 곡률을 못 잡고, 9차는 모든 점을 지나지만 점 사이에서 엉뚱하게 출렁입니다.

용량을 줄이는 다른 방법이 정규화입니다. 가중치 감쇠는 비용에 가중치 크기의 제곱합을 더해, 꼭 필요하지 않은 큰 계수를 억누릅니다. 같은 9차 다항식이라도 λ를 적당히 주면 이차 함수에 가까운 모양을 되찾습니다 (Goodfellow 그림 5.5, Murphy 7.5절의 능형 회귀).

J(w) = MSEtrain + λ wᵀwλ가 클수록 단순한 함수를 선호합니다. λ = 0이면 정규화가 없습니다 (Goodfellow 식 5.18).

검증 세트와 교차검증

차수나 λ 같은 하이퍼파라미터를 테스트 데이터로 고르면, 테스트 데이터가 더 이상 "처음 보는 데이터"가 아니게 됩니다. 그래서 학습 데이터의 일부를 떼어 검증 세트로 씁니다. Goodfellow(5.3.1절)는 보통 학습 데이터의 약 80%로 학습하고 20%로 검증한다고 적습니다. 데이터가 적으면 데이터를 k개로 나눠 돌아가며 검증하는 k-겹 교차검증을 씁니다.

어떤 모델도 모든 문제에서 최고일 수는 없습니다. 이를 공짜 점심은 없다 정리라고 합니다 (Murphy 1.4.9절). 그래서 문제마다 모델과 하이퍼파라미터를 검증 데이터로 골라야 합니다.

6장

분류: k-최근접 이웃과 로지스틱 회귀

교재: Murphy 1.4.2절, 1.4.6절, 8.1–8.3절 · Goodfellow 5.7.1절, 5.7.3절, 6.2.2절

k-최근접 이웃 (k-NN)

가장 단순한 분류기는 새 점과 가장 가까운 학습 점 K개를 보고, 그중 많은 쪽 클래스로 판정합니다 (Murphy 1.4.2절). 따로 학습할 매개변수가 없고 학습 데이터 자체가 모델입니다. 이런 모델을 비모수 모델이라고 합니다. K가 작으면 경계가 학습 점 하나하나에 휘둘리고, K가 크면 경계가 매끄러워집니다.

p(y = c | x, D, K) = (1/K) Σi ∈ NK(x) I(yi = c)NK(x)는 x와 가장 가까운 학습 점 K개, I는 조건이 참이면 1인 지시 함수입니다 (Murphy 식 1.2).

로지스틱 회귀

로지스틱 회귀는 선형회귀의 출력 wᵀx + b를 시그모이드 함수 σ(z) = 1/(1 + e−z)에 넣어 0과 1 사이의 확률로 바꿉니다. 이름에 회귀가 들어가지만 분류 모델입니다. p(y = 1 | x) = 0.5가 되는 곳, 곧 wᵀx + b = 0인 직선이 결정 경계입니다 (Murphy 8.2절).

비용 함수로는 정답 클래스에 매긴 확률의 음의 로그를 평균한 교차 엔트로피(음의 로그 가능도)를 씁니다. 정답에 높은 확률을 주면 비용이 작고, 정답에 낮은 확률을 주면 비용이 크게 늘어납니다. 정규 방정식 같은 닫힌 해가 없어서 경사하강법으로 풉니다 (Murphy 8.3절, Goodfellow 5.7.1절).

J(w, b) = −(1/m) Σi [ yi log σ(wᵀxi + b) + (1 − yi) log(1 − σ(wᵀxi + b)) ]기울기는 ∇wJ = (1/m) Σi (σ(wᵀxi + b) − yi) xi로, 선형회귀의 기울기와 모양이 같습니다 (Murphy 식 8.5).

7장

모델 평가: 정확도만으로는 부족하다

교재: Goodfellow 5.3절, 11.1절 · Murphy 5.7.2절

Goodfellow(11.1절)의 예입니다. 백만 명에 한 명꼴로 걸리는 희귀병 검사를 만든다고 합시다. 무조건 "병 없음"이라고 답하는 분류기도 정확도가 99.9999%입니다. 정확도가 높아도 쓸모없는 모델일 수 있다는 뜻입니다.

그래서 양성 클래스를 따로 봅니다. 정밀도(precision)는 모델이 양성이라고 한 것 가운데 실제로 양성인 비율이고, 재현율(recall)은 실제 양성 가운데 모델이 찾아낸 비율입니다. 두 값을 하나로 합칠 때는 조화평균인 F 점수를 씁니다. 정밀도는 2장의 베이즈 계산에서 본 사후 확률 p(병 | 양성)과 같은 양입니다.

분류기는 보통 점수나 확률을 내고, 그 값이 임계값을 넘으면 양성으로 판정합니다. 임계값을 낮추면 더 많이 찾아내지만(재현율 상승) 헛경보도 늘고(정밀도 하락), 높이면 그 반대입니다. 임계값을 옮기며 그린 정밀도–재현율 곡선(PR 곡선)이 이 맞바꿈을 보여 줍니다. 어느 오류가 더 비싼지는 문제마다 다릅니다 (Murphy 5.7.2절).

정밀도 = TP / (TP + FP), 재현율 = TP / (TP + FN), F = 2pr / (p + r)TP는 맞게 찾은 양성, FP는 헛경보, FN은 놓친 양성입니다 (Goodfellow 11.1절).

8장

비지도 학습: k-평균과 PCA

교재: Goodfellow 2.12절, 5.8절 · Murphy 1.3절, 11.4.2.5절, 12.2절, 25.1절

k-평균 군집화

k-평균은 데이터를 K개의 무리로 나눕니다. 중심 K개를 정한 뒤 두 단계를 번갈아 반복합니다. 각 점을 가장 가까운 중심의 무리에 배정하고, 각 중심을 자기 무리 점들의 평균으로 옮깁니다. 배정이 더 바뀌지 않으면 멈춥니다 (Goodfellow 5.8.2절, Murphy 알고리즘 11.1).

반복할 때마다 각 점에서 자기 중심까지 거리 제곱의 합(왜곡)이 줄어들지만, 그렇게 도달한 답이 가장 좋은 답이라는 보장은 없습니다. 결과가 처음 중심을 어디에 두었는지에 따라 달라집니다. K를 정하는 일도 쉽지 않습니다. K를 늘리면 왜곡은 계속 줄어들기 때문입니다. Murphy(11.4.2.5절)는 k-평균을 가우스 혼합 모델의 EM 알고리즘을 단순화한 형태로 설명합니다.

주성분 분석 (PCA)

PCA는 데이터를 더 적은 수의 축으로 요약합니다. 데이터를 한 축에 투영했다가 다시 원래 공간으로 되돌렸을 때 잃는 정보(재구성 오차)가 가장 작은 축을 찾습니다. 이 축은 투영한 데이터의 분산이 가장 큰 방향과 같고, 공분산 행렬의 가장 큰 고유값에 해당하는 고유벡터입니다 (Goodfellow 2.12절, Murphy 12.2.1절). PCA가 만든 새 좌표들은 서로 상관이 없어집니다 (Goodfellow 5.8.1절).

9장

신경망: XOR에서 다층 퍼셉트론까지

교재: Goodfellow 6.1–6.4절 · Murphy 16.5절, 28.3절

선형 모델로는 풀 수 없는 가장 작은 문제가 XOR입니다. 두 입력 중 정확히 하나만 1일 때 1을 내야 합니다. Goodfellow(6.1절)가 네 점에 선형 모델을 최소제곱으로 맞추면 w = 0, b = 0.5가 나옵니다. 모든 입력에 0.5를 답하는 셈입니다. x₁이 0일 때와 1일 때 x₂의 효과가 반대여야 하는데, 선형 모델은 x₂에 하나의 계수만 줄 수 있기 때문입니다.

해법은 입력을 새 표현으로 바꾸는 은닉층입니다. 은닉층은 h = g(Wᵀx + c)를 계산하고, 출력층은 h 위에서 다시 선형 모델 y = wᵀh + b를 적용합니다. 여기서 g가 활성화 함수입니다. g가 없으면 층을 몇 개 쌓아도 전체가 하나의 선형 함수라서 아무 도움이 되지 않습니다. 오늘날 기본 추천은 ReLU, g(z) = max(0, z)입니다.

W = [[1, 1], [1, 1]], c = [0, −1]ᵀ, w = [1, −2]ᵀ, b = 0Goodfellow 식 6.4–6.6이 제시한 XOR 해입니다. ReLU를 지나면 (0,1)과 (1,0)이 은닉 공간의 한 점 (1,0)으로 모이고, 네 점이 직선 하나로 갈라집니다.

보편 근사 정리와 깊이

보편 근사 정리에 따르면, 은닉층이 하나뿐이라도 은닉 단위가 충분히 많으면 신경망은 연속 함수를 원하는 만큼 정확하게 근사할 수 있습니다 (Goodfellow 6.4.1절). 다만 Goodfellow는 그 층이 감당할 수 없을 만큼 커질 수 있고, 학습이 그 해를 찾지 못하거나 잘 일반화하지 못할 수 있다고 덧붙입니다. 많은 경우 층을 깊게 쌓으면 더 적은 단위로 같은 함수를 표현하고 일반화 오차도 줄일 수 있습니다.

10장

역전파

교재: Goodfellow 6.5절, 6.3.2절, 8.2.5절, 11.5절 · Murphy 16.5.4절

경사하강법을 쓰려면 모든 매개변수에 대한 비용의 기울기가 필요합니다. 신경망은 함수가 여러 겹으로 합성된 구조라서, 기울기는 미분의 연쇄 법칙으로 구합니다. y = g(x), z = f(y)이면 dz/dx = (dz/dy)(dy/dx)입니다 (Goodfellow 식 6.44).

계산을 연산 하나하나를 노드로 하는 계산 그래프로 그리면 이해가 쉽습니다. 순전파는 입력에서 출력 쪽으로 값을 계산하고, 역전파는 출력에서 입력 쪽으로 거슬러 가며 각 노드의 기울기를 계산합니다. 역전파는 중간 결과를 저장해 두었다가 다시 쓰므로, 같은 식을 반복해서 계산하는 낭비를 피합니다 (Goodfellow 6.5절).

직접 짠 역전파 코드는 버그가 생기기 쉽습니다. Goodfellow(11.5절)는 역전파로 구한 기울기를 유한 차분으로 구한 수치 기울기와 비교해 보라고 권합니다. 아래 실험이 그 비교를 보여 줍니다.

기울기 소실과 폭주

층이 깊으면 연쇄 법칙의 곱셈이 길어집니다. 층마다 1보다 작은 값이 곱해지면 기울기가 지수적으로 작아지고(소실), 1보다 큰 값이 곱해지면 지수적으로 커집니다(폭주) (Goodfellow 8.2.5절). 시그모이드는 입력이 크거나 작으면 기울기가 거의 0이 되는 포화 구간이 넓고, 미분의 최댓값도 0.25입니다. 이 때문에 깊은 신경망의 은닉층에는 잘 쓰지 않습니다 (Goodfellow 6.3.2절).

11장

심층 신경망 학습하기: 최적화와 정규화

교재: Goodfellow 7.8절, 7.12절, 8.1–8.5절 · Murphy 8.5절, 16.5.6절

모멘텀과 Adam

골짜기가 길쭉하면 기본 경사하강법은 지그재그로 느리게 내려갑니다. 모멘텀은 지난 걸음들의 방향을 속도 v로 누적합니다. 일관된 방향으로는 점점 빨라지고, 계속 바뀌는 방향은 서로 상쇄됩니다. 업데이트는 v ← αv − ε∇J, θ ← θ + v이고, α로는 0.5, 0.9, 0.99를 흔히 씁니다 (Goodfellow 8.3.2절).

Adam은 매개변수마다 학습률을 따로 조절하는 적응형 방법입니다. 기울기의 평균(1차 모멘트)과 제곱의 평균(2차 모멘트)을 함께 추적합니다. Goodfellow 알고리즘 8.7의 추천 기본값은 학습률 0.001, 감쇠율 ρ₁ = 0.9와 ρ₂ = 0.999, 안정화 상수 10⁻⁸입니다 (8.5.3절). 하이퍼파라미터에 비교적 덜 민감해 널리 쓰입니다.

조기 종료와 드롭아웃

큰 신경망을 오래 학습시키면 학습 손실은 계속 줄지만, 검증 손실은 어느 순간부터 다시 오릅니다. Goodfellow 그림 7.3의 비대칭 U자 곡선입니다. 조기 종료는 학습 중 검증 손실이 가장 낮았던 때의 매개변수를 저장해 두었다가 그것을 결과로 씁니다 (7.8절). 가장 흔하게 쓰는 정규화 방법입니다.

드롭아웃은 학습할 때마다 뉴런 일부를 무작위로 끕니다. 보통 입력 단위는 0.8, 은닉 단위는 0.5의 확률로 남깁니다 (7.12절). 신경망이 특정 뉴런에 기대지 못하게 되고, 많은 작은 신경망의 앙상블을 학습하는 효과가 납니다. 평가할 때는 모든 뉴런을 켭니다.

12장

합성곱 신경망

교재: Goodfellow 9.1–9.3절 · Murphy 16.5.1절

이미지는 화소가 격자로 늘어선 데이터입니다. 합성곱은 작은 가중치 격자인 커널을 이미지 위로 밀며, 겹치는 화소와 커널 값을 곱해 더합니다. 그 결과를 특징 맵이라고 합니다. 수학의 합성곱은 커널을 뒤집어 곱하지만, 대부분의 머신러닝 라이브러리는 뒤집지 않는 교차상관을 구현하고 그것을 합성곱이라 부릅니다 (Goodfellow 9.1절).

Goodfellow(9.2절)는 합성곱의 세 가지 장점을 듭니다. 출력 하나가 입력의 작은 영역에만 연결되는 희소 상호작용, 같은 커널을 모든 위치에 다시 쓰는 매개변수 공유, 입력이 이동하면 출력도 같은 만큼 이동하는 이동 등변성입니다. 그림 9.6의 예에서 높이 280, 너비 320 화소인 이미지의 세로 경계를 찾는 데는 원소 2개짜리 커널이면 충분합니다. 같은 변환을 행렬 곱셈으로 쓰면 행렬 원소가 80억 개를 넘습니다.

전형적인 합성곱 층은 세 단계입니다. 여러 커널로 합성곱을 하고, ReLU 같은 비선형 함수를 적용하고(검출 단계), 풀링을 합니다 (9.3절). 최대 풀링은 주변 영역의 최댓값만 남겨, 입력이 조금 움직여도 출력이 거의 바뀌지 않게 합니다.

다음에 공부할 것

이 학습서는 두 교재의 입문 부분까지만 다룹니다. 이어서 공부할 주제와 교재 위치는 다음과 같습니다.

  • 순환 신경망과 LSTM: 문장이나 시계열처럼 순서가 있는 데이터를 다룹니다 (Goodfellow 10장).
  • 오토인코더와 표현 학습: 데이터를 압축했다가 되살리며 유용한 표현을 배웁니다 (Goodfellow 14–15장).
  • 심층 생성 모델: VAE와 GAN처럼 새 데이터를 만들어 내는 모델입니다 (Goodfellow 20장).
  • 확률 모델의 관점: 베이즈 통계, 그래프 모델, 가우스 과정, 혼합 모델과 EM은 Murphy가 깊이 다룹니다 (Murphy 5, 10, 11, 15장).
